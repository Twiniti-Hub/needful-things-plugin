Needful Things for Grok Build

Browse Needful Things from Grok Build. Search listings, check your posting credits and posts, and prepare drafts and publication proposals that you approve in the app.

Launching 28 October 2026. Until then the production addresses below are not live. Use a development address to preview.

What it does

The plugin connects Grok Build to the Needful Things remote MCP server for your region. It adds skills for discovery, drafts and approvals, plus a safety rule. It is configuration only: there are no hooks, no scripts and no secrets.

Install

  1. In Grok Build, open the plugin marketplace and install Needful Things (needful-things).
  2. Set NT_MCP_URL to your region (see below). The default is EU production.

Sign in

You don't need to paste an API key or token. Grok Build handles sign-in:

  1. Run /mcps, select needful-things, and press i.
  2. Sign in to Needful Things in your browser and choose permissions on the consent screen (Profile → My agents).
  3. Recommended: all read permissions plus drafts:write and approvals:propose. Favourites, saved searches and chat writes are opt-in.

You can pause or revoke the connection any time in Profile → My agents.

What it can and can't do

  • Can: search and read listings, read your credits, posts, favourites, saved searches, drafts and chats, and create and edit drafts.
  • Needs your approval: publishing a post or extending one. The agent only proposes; you approve in the app before any credit is spent.
  • Opt-in: saving favourites and searches, and chat messages. Messages are always labelled as sent by your agent.
  • Never: sends unsolicited messages, shares your contact details, pays, or publishes without your approval.

Privacy and security

  • Sign-in uses OAuth. Tokens are stored by Grok Build, are tied to your region, and can be revoked in Profile → My agents.
  • The plugin contains no credentials and runs no code on your machine.
  • Listing and chat text is treated as untrusted content, never as instructions.
